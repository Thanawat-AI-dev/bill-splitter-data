# 🧾 หารบิล (Bill Splitter)

แอปสำหรับสร้าง "โปรเจกต์" คิดเงินแต่ละครั้ง กรอกเมนู/รายชื่อคน/ใครกินอะไร
แล้วสรุปเป็นแดชบอร์ด พร้อม Export เป็น PDF/รูปภาพ — ไม่มีเซิร์ฟเวอร์ฝั่งหลังบ้าน
รันเป็นเว็บไซต์ static ล้วน ๆ ได้เลย (เช่นบน GitHub Pages)

ระบบเก็บข้อมูลหลักคือ **Firebase Firestore + Firebase Authentication**
(Email/Password สำหรับเจ้าของบิล, Anonymous สำหรับเพื่อนที่กดลิงก์แชร์)
เจ้าของบิลสมัคร/เข้าสู่ระบบครั้งเดียว สร้างโปรเจกต์ผ่าน wizard 5 ขั้นตอน แล้วแชร์
ลิงก์ให้เพื่อนติ๊กเมนูของตัวเองแบบเรียลไทม์ — เพื่อนไม่ต้องสมัครบัญชี

แนวคิดของฟอร์มคำนวณอ้างอิงจากไฟล์ Google Sheet "Form_bill" (เมนู → รายชื่อคน →
ตารางนับ/หาร)

## โครงสร้างไฟล์

```
index.html          หน้าเว็บหลัก
style.css           ดีไซน์ (โทนใบเสร็จ/Glassmorphism มืด-สว่าง)
app.js              ลอจิกทั้งหมด: wizard, การคำนวณ, Firebase, กราฟ, Export PDF
firebase-config.json Firebase web config (apiKey/authDomain/projectId/appId) — ต้องมีไฟล์นี้ให้แอปโหลดสำเร็จ
firestore.rules     กฎความปลอดภัย Firebase Firestore สำหรับโหมดแชร์หลายคน
```

## เริ่มใช้งาน (สำหรับผู้ใช้ทั่วไป)

ถ้ามีคนตั้งค่า Firebase และดีพลอยแอปไว้ให้แล้ว การใช้งานมีแค่นี้:

1. เปิดลิงก์แอป → หน้าแรกจะเป็นฟอร์ม เข้าสู่ระบบ/สมัครบัญชี — เฉพาะ**เจ้าของบิล**
   เท่านั้นที่ต้องมีบัญชี เพื่อนที่กดลิงก์แชร์ **ไม่ต้องสมัครหรือเข้าสู่ระบบ**
2. สมัครบัญชีด้วยอีเมล แล้วกด "+ สร้างโปรเจกต์ใหม่"
3. ทำตาม wizard 5 ขั้นตอน:
   1. **ข้อมูลบิล** — ชื่อ, วันที่, ร้าน, ส่วนลดรวม, ค่าบริการ %, VAT %
   2. **เมนู** — รายการอาหารและราคา (พิมพ์เองหรือนำเข้าจาก AI ก็ได้ ดูหัวข้อถัดไป)
   3. **รายชื่อคน** — ใส่ชื่อทุกคนที่ร่วมบิล
   4. **หารบิล** — ติ๊กว่าใครกินเมนูไหน (ระบบหารเฉลี่ยเฉพาะคนที่ติ๊ก) แล้วกด
      "📤 แชร์ลิงก์" เพื่อคัดลอกลิงก์ให้เพื่อน
   5. **สรุปผล** — แดชบอร์ด + ใบเสร็จสรุป + ปุ่ม Export PDF/รูปภาพ
4. แต่ละขั้นตอนบันทึกอัตโนมัติเมื่อกด "บันทึก & ถัดไป", "ย้อนกลับ" หรือ "💾 บันทึก"
   ที่หน้าสรุปผล

## ตั้งค่า Firebase (สำหรับผู้ที่ดีพลอยเอง)

1. สร้าง Firebase project ด้วยแผน Spark (ฟรี)
2. เปิด Firestore Database
3. เปิด Authentication → Sign-in method → เปิดทั้ง **Email/Password** (สำหรับ
   เจ้าของโปรเจกต์) และ **Anonymous** (สำหรับเกสที่กดลิงก์แชร์ — ไม่ต้องสมัครบัญชี)
4. Project settings → Your apps → Web app → คัดลอก Firebase config ลงไฟล์
   `firebase-config.json` (ต้องมีอย่างน้อย `apiKey`, `authDomain`, `projectId`,
   `appId`)
5. นำเนื้อหา `firestore.rules` ไปวางใน Firestore Rules แล้ว Publish
6. อัปโหลด `firebase-config.json` ไปพร้อม `index.html`, `style.css`, `app.js`
   ขึ้นโฮสต์ static ที่เลือก (เช่น GitHub Pages)

ถ้าลืมเปิด provider "Anonymous" ในขั้นตอนที่ 3 เกสจะเจอหน้าแจ้งเตือนให้ไปเปิดก่อน
ส่วนถ้า `firebase-config.json` หาย/กรอกไม่ครบ หน้าแรกจะโชว์แบนเนอร์แจ้งพร้อมปุ่ม
"🔄 ลองใหม่" แทนที่จะเป็นหน้าเปล่า

การกรอกของเกสจะซิงก์แบบเรียลไทม์ทั้งสองทาง (เกสเห็นเพื่อนคนอื่น, เจ้าของเห็นเกส
อัปเดตสด) โดยไม่ต้องกดรีเฟรช และเจ้าของสามารถกดปุ่ม **"🔒 ปิดรับการแก้ไขจากเกส"**
ที่หน้าสรุปผลเพื่อล็อกไม่ให้เกสแก้ไขเพิ่มได้ตลอดเวลา

## อ่านบิลจากรูปด้วย AI

ในขั้นตอน **2. เมนู** มีสองวิธีให้ AI อ่านรูปบิลแล้วเติมรายการเมนูให้อัตโนมัติ

### วิธีที่ 1 — อัปโหลดรูปในแอปโดยตรง (เร็วที่สุด)

1. กดปุ่ม **📷 อัปโหลดรูปบิล (AI อ่านให้อัตโนมัติ)**
2. ถ้ายังไม่เคยตั้งค่า จะมีข้อความให้ไปกรอก **Anthropic API Key** ในหัวข้อ
   "⚙️ ตั้งค่า AI อ่านบิลอัตโนมัติ" ก่อน (หาคีย์ได้ที่ console.anthropic.com —
   คีย์จะถูกเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ถูกส่งไปที่อื่น
   หรือ commit ขึ้น GitHub เนื่องจากแอปนี้เป็น static site ไม่มีเซิร์ฟเวอร์หลังบ้าน
   จึงต้องเรียก Anthropic API ตรงจากเบราว์เซอร์ — **อย่าใช้เครื่องคอมพิวเตอร์ส่วนรวม
   โดยไม่ล้าง localStorage ก่อนเลิกใช้งาน**)
3. เลือกรูปใบเสร็จ แอปจะส่งรูปให้ Claude อ่านและเติมรายการเมนูให้อัตโนมัติ
   (ควรตรวจสอบราคาอีกครั้งก่อนไปขั้นต่อไป — ถ้าสแกนรูปเดิมซ้ำ ระบบจะข้ามรายการที่
   ชื่อ+ราคาตรงกับของเดิมให้อัตโนมัติ ไม่เพิ่มซ้ำ)

### วิธีที่ 2 — ใช้ AI ภายนอกแล้ว import ไฟล์ JSON

1. กดปุ่ม **📋 Copy Prompt**
2. เปิด Claude, ChatGPT หรือ AI ที่อ่านรูปได้ วาง prompt ที่คัดลอกมา แล้วแนบรูปใบเสร็จ
3. AI จะสร้างไฟล์ `.json` ให้ดาวน์โหลด (prompt สั่งให้ AI ส่งเป็นไฟล์แนบ ไม่ใช่
   Markdown/code fence ในแชท)
4. กลับมาที่แอป ขั้นตอน **2. เมนู** กดปุ่ม **📥 นำเข้า JSON จาก AI** แล้วเลือกไฟล์นั้น
   รายการจะถูกเติมเข้าตารางเมนูให้อัตโนมัติ (ควรตรวจสอบราคาอีกครั้งก่อนไปขั้นต่อไป
   เผื่อ AI อ่านตัวเลขบางจุดผิดจากรูปที่เอียง/เลือนราง — ถ้ากดนำเข้าไฟล์เดิมซ้ำ
   ระบบจะข้ามรายการที่ชื่อ+ราคาตรงกับของเดิมให้อัตโนมัติ ไม่เพิ่มซ้ำ)

ไฟล์ JSON รองรับ `items`, `totalDiscount`, `serviceChargePercent`, `vatPercent`,
`place`, `date` และ `billName`

### ตั้ง Admin
1. สมัครบัญชีในแอปด้วยอีเมลของ Admin ก่อน
2. ไปที่ Firestore → collection `users`
3. เปิด document ของบัญชีนั้น
4. เปลี่ยน field `role` จาก `user` เป็น `admin`
5. กลับมา refresh แอป จะเห็นปุ่ม **ผู้ดูแลระบบ** ที่หัวเว็บ

## วิธีคำนวณ

- ส่วนลดรวม (บาท) จะถูกหารเฉลี่ยให้แต่ละเมนูตาม **สัดส่วนราคา** ของเมนูนั้น
  เทียบกับยอดรวมทั้งบิล (ตามแนวคิดคอลัมน์ "สัดส่วนลด" ในไฟล์ Form_bill)
- ราคาหลังหักส่วนลดของแต่ละเมนู จะถูกหารเฉลี่ยเท่า ๆ กันเฉพาะคนที่ติ๊กว่ากิน
  เมนูนั้น (ตามแนวคิด "ตารางนับหาร")
- ค่าบริการและ VAT คำนวณจากยอดรวมหลังหักส่วนลด แล้วเฉลี่ยคืนให้แต่ละคน
  ตามสัดส่วนยอดที่ตัวเองกิน
- ยอดต่อคนที่แสดงผลจะถูกปัดเศษให้รวมกันตรงกับยอดรวมสุทธิเป๊ะเสมอ (ไม่มีเศษสตางค์
  หายหรือเกิน)

## ดีพลอยขึ้น GitHub Pages

1. Push ไฟล์ทั้งหมด (`index.html`, `style.css`, `app.js`, `firebase-config.json`,
   `firestore.rules`) ขึ้นรีโพ
2. ไปที่ **Settings → Pages** ของรีโพนั้น → Source เลือก branch ที่ต้องการ
   (เช่น `main`) และโฟลเดอร์ `/ (root)`
3. รอสักครู่แล้วเปิดลิงก์ที่ GitHub มอบให้ (รูปแบบ
   `https://<username>.github.io/<repo>/`)
4. อย่าลืมเพิ่มโดเมนนี้ใน Firebase Authentication → Settings → Authorized domains
   ไม่งั้นการเข้าสู่ระบบจะขึ้น error `auth/unauthorized-domain`

## ฟีเจอร์เพิ่มเติม

### 👥 รายชื่อคนที่บันทึกไว้ใช้ซ้ำ (โหมด GitHub PAT เท่านั้น)
ถ้าเปิดใช้โหมด GitHub PAT (ดูหัวข้อถัดไป) ทุกชื่อที่กรอกในขั้นตอน "3. รายชื่อคน"
จะถูกบันทึกไว้ในกลุ่มเดียวที่ใช้ร่วมกันได้ทุกโปรเจกต์ (เก็บไว้ที่
`people/_saved.json` บนรีโพ GitHub) โปรเจกต์ถัดไปจะมีชิป "รายชื่อที่บันทึกไว้"
ให้คลิกเพิ่มได้ทันทีโดยไม่ต้องพิมพ์ใหม่ (โหมด Firebase ยังไม่มีฟีเจอร์นี้)

### ✓ เลือกทุกคนต่อรายการเมนู
ในตารางขั้นตอน "4. หารบิล" มีคอลัมน์ "ทุกคน" — ติ๊กช่องนี้ในแถวเมนูไหนจะติ๊กให้
ทุกคนหารเมนูนั้นทันที (ใช้ปุ่ม "✓ ทุกคนหารทุกเมนูเท่ากัน" ได้เหมือนกัน ถ้าต้องการ
ให้ทุกคนหารทุกเมนูทั้งบิลพร้อมกัน)

### 🧾 PDF/รูปภาพขนาดใบเสร็จจริง
ปุ่ม Export PDF/รูปภาพ ในหน้าสรุปผล (และหน้าสรุปของเกสแต่ละคน) จะได้ไฟล์ขนาดกว้าง
คงที่ 80mm (เท่าใบเสร็จร้านสะดวกซื้อ) ยาวเท่าที่เนื้อหาต้องการ อยู่ในไฟล์เดียว
หน้าเดียว ไม่ตัดแบ่งหน้าแบบ A4

## โหมด GitHub PAT (legacy)

โค้ดยังมีฟังก์ชันเก็บข้อมูลผ่าน GitHub REST API (ใช้ Personal Access Token ที่
ผู้ใช้กรอกเอง เก็บไว้ใน localStorage) หลงเหลืออยู่ใน `app.js` จากเวอร์ชันก่อนย้าย
มาใช้ Firebase แต่ **ไม่มีปุ่มในหน้าเว็บให้เปิดใช้งานโหมดนี้แล้ว** — ถ้าต้องการใช้
โหมดนี้ต้องเขียน UI ตั้งค่า (owner/repo/token) เชื่อมกับฟังก์ชัน `saveSettingsToStorage`
เพิ่มเอง ไม่แนะนำสำหรับผู้ใช้ทั่วไป ใช้ Firebase ตามหัวข้อด้านบนแทน

หากยังเลือกใช้โหมดนี้:
- ใช้ **Fine-grained PAT** ที่จำกัดสิทธิ์เฉพาะรีโพที่ใช้เก็บข้อมูล และให้สิทธิ์
  เฉพาะ Contents (Read/Write) เท่านั้น
- อย่าแชร์ลิงก์หน้าจอที่มีโทเค็นปรากฏอยู่ และอย่า commit ไฟล์ settings ใด ๆ
  ที่มีโทเค็นอยู่ในนั้น — โทเค็นจะถูกเก็บไว้ใน localStorage ของเบราว์เซอร์แต่ละคน
  เท่านั้น ไม่ถูกส่งไปที่อื่นหรือ commit ขึ้น GitHub
- หากใช้เครื่องคอมพิวเตอร์ส่วนรวม ให้ล้าง localStorage ก่อนเลิกใช้งาน
